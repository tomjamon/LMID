# Launch My ID - Chrome extension

## About it

LMID is a Chrome extension to quickly open your favorite websites with an ID, for example: `https://www.twitter.com` and `https://www.twitter.com/your-handle`.

Links are preconfigured with popular websites (Facebook, YouTube, Instagram, etc.), but you can change them as you wish. Up to 9 links are configurable.

The default shortcut is **Ctrl+Shift+1** (Windows/Linux) or **⌥+Shift+A** (Mac). If it does not work, open [chrome://extensions/shortcuts](chrome://extensions/shortcuts) and assign **Open the application launcher** manually.
